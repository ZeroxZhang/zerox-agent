Building Agent

Local-First Desktop AI Agent MVP

核心价值

从零构建的 macOS 桌面 AI Agent。主打本地优先、隐私安全与高度可扩展的技能生态。让 AI 真正成为你的本地工作流助手。

核心功能

🧠 智能调度

多模式任务调度与 Agent Runner，支持复杂工作流的自动执行与状态管理。

🔌 技能生态

自动扫描本地 Skills 目录，动态加载能力。支持自定义技能扩展。

🔒 权限管控

细粒度的工具权限管理，确保 Agent 操作安全可控，防止越权执行。

💾 本地记忆

内置 Local Memory 系统，持久化上下文与历史交互，越用越懂你。

⚙️ 模型配置

灵活的模型配置与连通性测试，支持多种 LLM 后端接入。

🖥️ 桌面体验

基于 Electron 构建的原生级桌面体验，无缝集成 macOS 系统能力。

技术栈

Electron React TypeScript Vite macOS Native
