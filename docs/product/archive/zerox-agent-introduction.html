Local-first desktop agent

让本地 Agent 真正可控。

Zerox 把模型、工具、权限、记忆和检查点封装进一条可复查的本地运行链路。

它解决的不是回答问题，而是让动作可信。

普通聊天产品只负责生成内容。Zerox 负责把一句自然语言要求，变成有边界、有过程、有证据、能继续的本地运行。

它是个人 Agent 的桌面控制平面，不是套在模型外面的聊天壳。

Electron 主进程持有真正的执行权。React 界面只展示状态和收集授权，模型不能绕过主进程直接碰文件、Shell、网络或长期记忆。

不是云端 Agent 托管
会话、轨迹、检查点和记忆默认写入本机 userData。
不是无界自治循环
每次运行受轮次、工具、Token 和墙钟预算约束。
不是静默自我修改
学习先成为候选项，只有用户审核接受后才进入程序性记忆。

四条信任原则，决定每个实现细节。

安全不是单独的一张设置卡片，而是从运行上下文、工具授权、数据落盘到学习应用的连续约束。

本地优先

API Key 使用 Electron safeStorage 加密。JSON 与 JSONL 是完整默认数据源，不依赖云端 worker 才能执行或恢复。

权限明确

工具调用同时经过规则、任务策略、工作区沙箱和高风险确认。任何一层收紧，模型都不能自行放宽。

中断可恢复

工具结果之后立即写检查点。应用退出、模型失败或用户暂停后，可以从已保存的消息和进度继续。

过程可查

模型请求、工具调用、权限拒绝、上下文压缩和验收结果进入轨迹。学习必须先经过用户审核。

一次运行，穿过六个可观察边界。

Chat、Goal 里程碑与定时任务共享同一条生产级 Agent Loop。表面入口不同，预算、授权、工具观察与检查点语义保持一致。

  1. CONTEXT

    冻结运行上下文

    固定工作区根目录、沙箱、技能、可见工具、记忆作用域和检查点策略，形成不可变执行包。

  2. MODEL

    请求模型

    注入系统提醒，必要时压缩历史，再通过选定 Provider 流式或重试请求模型。

  3. AUTH

    授权工具调用

    解析参数与 ShellPlan，检查规则、任务策略、工作区路径以及是否需要用户确认。

  4. EXEC

    执行并返回观察

    动态工具注册表校验参数后执行。成功和失败都会成为模型可见观察，不会被静默吞掉。

  5. RECORD

    写入检查点与轨迹

    持久化消息、工具计数、下一动作和结构化事件，使恢复、回放与审计拥有同一份证据。

  6. ACCEPT

    验收或继续

    普通对话生成最终答复。Goal 还会执行确定性检查、证据清单、模型裁决和修复策略。

LOOP GUARDS

重复工具调用、碎片化调用、连续失败、超出 Token、工具、轮次或墙钟预算都会触发暂停或失败分类，避免 Agent 在同一模式里空转。

模型提出动作，主进程决定能不能做。

最终授权始终留在 Electron 主进程。Renderer 只能发起请求和展示结果，不能代替 ToolAuthorizationService 作出执行决定。

Shell 还会先被解析为结构化 ShellPlan。控制符、管道、重定向和命令替换会改变授权判断，不能靠前缀伪装成安全命令。

运行时权限规则

PermissionRule[] 可明确 allow、deny 或 ask，并记录匹配规则。

任务权限策略

文件目录、Shell 命令、网页域名和记忆读写按任务白名单判断。

工作区沙箱

read_only、workspace_write、网络与 Shell 模式继续收紧任务策略，默认禁止越界。

高风险人工确认

极高危动作即使命中允许规则，没有确认通道也会失败关闭。

执行器与超时

参数校验通过后才调用工具，超时和取消信号绑定到同一个底层任务。

每个决定都会留下审计事件

允许、拒绝、人工批准与沙箱越界都能在 Runs 和工具审计中回查。

五层结构，把界面和执行权分开。

仓库采用 Electron、Preload、React Renderer、Main Process 服务和本地存储分层。依赖注入容器负责把服务按需组合起来。

谁会真正需要它？

独立开发者与 Power User

希望 Agent 能操作本地文件和工具，又不愿把工作状态交给托管平台。

隐私敏感的知识工作

整理下载、导出资料、写报告、巡检目录，并要求过程可以回查。

关心 Agent 控制权的人

不仅想知道最后答案，还要知道它做过什么、为什么获准、能否停止和恢复。

它刻意不做什么？

  • 不把本地状态交给云端 Agent worker。
  • 不执行没有预算和终止条件的无限自治任务。
  • 不让 Renderer 或模型绕过主进程权限网关。
  • 不把未经审核的学习自动写进代码或 Skill。
  • 不把自己定位成通用聊天伙伴或纯编码 CLI。
