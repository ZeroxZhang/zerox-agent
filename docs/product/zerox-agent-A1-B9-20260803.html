ONE WORKSPACE · FOUR SURFACES

从对话开始，在证据中结束

主流程只保留四个入口。复杂诊断、技能、工具、记忆、学习与评测进入 Settings，不与核心工作流争夺注意力。

01 · CHAT

会话

普通 Chat、Goal Mode、工作区、Skill、规划确认、执行、验收与恢复都在同一会话。

02 · RUNS

任务记录

先看结果、失败原因和下一步；checkpoint、工具、轨迹与诊断细节按需展开。

03 · TASKS

任务

把稳定工作保存为每日、工作日、每周或固定间隔执行的本地自动任务。

04 · SETTINGS

设置

先连接模型，再管理工具、记忆、技能、学习、评测与系统健康。

TRUST IS THE PRODUCT

可靠性来自同一条状态链

renderer 只负责展示和发起操作。Plan 采用、Goal 状态、工具授权、验收证书与持久化事务的最终裁决都在主进程。

本地
会话、Plan、Goal、运行记录、记忆与审计默认保存在 Mac；外部模型只接收完成当前请求所需的上下文。
可控
普通范围内操作可自动授权；极高风险、不可逆或扩大权限的动作仍必须由用户确认。
可恢复
checkpoint、Plan 谱系和 session-work 投影共同恢复原 Goal，不把失败任务误路由成无关 Chat。
可验收
主消息、进度、恢复入口和任务列表读取同一持久状态；只有有效证据与证书才能宣布目标达成。
CONNECT · EXTEND · REMEMBER

能力来自可配置连接，不来自黑箱

模型、Skills、工具和记忆都通过显式连接、权限与来源进入运行；每个 Plan 固定自己的模型与契约 revision。

模型连接

同一服务商可保存多个 Connection 与 Model Profile。凭证由 safeStorage 加密，修改配置会清除旧验证。

Skills 与 MCP

SKILL.md 定义输入、执行方式和权限；来源与哈希被固定，MCP 自动启动必须显式开启。

工具与记忆

工具经过主进程授权和工作区沙箱；记忆支持关键词与可选向量检索，学习候选必须人工审核。
