01 / PRINCIPLES

设计原则

Zerox Agent 是一款面向专业开发者的通用 AI Agent。界面必须像一位可靠的同事：专业、克制、简洁。以下四条原则是所有设计与实现决策的最高依据。

P1

克制的色彩

界面 95% 以上由中性灰阶构成。彩色只承担两种职责：标记关键操作（Accent）与传达状态（语义色）。永远不用颜色做装饰。

P2

内容优先

用户的工作内容是主角，界面容器退居幕后——1px 细边框、低饱和背景、轻量阴影，绝不与内容争夺注意力。

P3

秩序的网格

所有尺寸取自同一数值体系：4pt 间距网格、8 级字号、5 档圆角、4 级阴影。不存在"看起来差不多"的随意取值。

P4

原生的手感

遵循 macOS 惯例：系统字体栈、毛玻璃材质、标准控件尺寸与焦点环。任何操作在 150ms 内给出可感知反馈，动效解释因果而非炫技。

02 / COLOR

色彩系统

基础背景锁定 #F3F3F3。主色六套候选，本轮按色相拉开重选：蓝色仅保留石墨蓝一套，其余参照 Alibaba、Anthropic、T-Mobile、Netflix、OpenAI 等非蓝品牌；绿与紫按反馈整体排除。所有方案 500 填充 × 白字对比度 ≥ 4.5:1，点击「应用此方案」全文档实时预览，建议配合 Dark 模式对比。

09 / ACCESSIBILITY

可访问性

克制不等于低对比。所有正文级文字满足 WCAG 2.1 AA（≥4.5:1），控件图形满足非文本对比（≥3:1）。

组合（Light）示例对比度判定
text-primary / bg-base正文文本 Aa≈13.1:1AAA ✓
text-secondary / bg-base次级说明 Aa≈4.9:1AA ✓
text-tertiary / bg-base占位/装饰 Aa≈2.9:1仅装饰 ✕
on-accent / accent-500（当前方案）主按钮 Aa≥4.5:1AA ✓ 六套均校验
#fff / danger-fill危险按钮 Aa≈4.8:1AA ✓
text-tertiary 禁止用于承载必读信息品红 #E20074 为 4.7:1 恰过线（其链接色已加深为 #C40064）；曜石 Light ≈15:1Dark 模式各组合同样通过 AA 校验
键盘焦点可见性
焦点环: 3px --color-accent-ring + 1px accent 描边仅 :focus-visible 触发，鼠标点击不显示Tab 顺序 = 视觉阅读顺序
最小可点击区域
28×28 ✓

图形可小至 16px，但命中区域不得小于 28×28（鼠标）/ 44×44（触控板手势目标建议）。虚线即不可见的扩展命中区。

其他约定

状态从不只靠颜色传达——始终伴随图标或文字（如"已拦截"标签同时具备色彩与文案）；全站尊重 prefers-reduced-motion，命中时所有动效压缩至 0.01ms；模态打开时焦点移入并循环，Esc 恒可关闭；所有图标按钮提供 aria-label；长任务进度对屏幕阅读器以 aria-live 通告。
