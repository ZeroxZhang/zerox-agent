01 / INTENT

会话输入

02 / CONTRACT

目标与计划

Goal Contract 冻结结果与约束；Direct 或 Debate 生成可审查路径。

03 / RUNTIME

受管执行

最终验收

成功标准通过并生成有效证书后，Goal 才会进入 achieved。

DEFAULT PLANNING

Direct

调查、生成、独立冷审与质量门禁。适合目标清晰、路径可直接收敛的工作。

ADVERSARIAL PLANNING

Debate

A/B 对抗审查、C 独立综合。适合约束复杂、方案争议大或需要保留少数意见的工作。

Plan steps_completed 不等于 Goal achieved。

路径执行完成后仍要按 Goal Contract 做最终验收；证据不足时，系统会如实保留未达成状态。

设置
